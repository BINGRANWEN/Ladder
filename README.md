# ladder 🪜

> **用两杯咖啡换前进的方向。**

ladder 是一款轻付费咨询小程序的 MVP 原型：对标 LinkedIn 的履历形式，25 分钟 / 50–100 元，聚焦**成长型问题**——应届求职、跳槽选公司、职场转型。

## 它解决什么问题

- 信息爆炸时代，缺的不是信息，是**经过验证的真实经验**
- 市面求职陪跑动辄 1 万+，把咨询从奢侈品打回日用品
- 小红书 coffee chat 现象证明：需求已在发生，缺的是供给的组织化

## 核心设计原则

1. **隐私保护是默认，不是选项** —— 脱敏标签、协议强制勾选、通话四角水印、平台内置音视频
2. **飞单防御写进产品流程** —— 预约协议 + 通话默认禁录 + 让"留下来比跳出去更划算"
3. **MVP 收得极窄** —— 只做：答主填表 → 用户浏览预约 → 通话 → 结算+评价

## 页面结构

```
用户旅程：P1 首页 → P2 答主详情 → P4 预约支付 → P5 通话中 → P6 评价
答主旅程：P3 答主填表（5 步）→ P7 我的（双角色）
```
