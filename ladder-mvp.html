📌 MVP 设计原则（先看这个）

① 第一版不做完整 LinkedIn只要 7 个核心页面，跑通「看→选→约→聊→评」最小闭环

⑤ 不做 Web，先做小程序移动优先，路径最短，复用微信生态

📋 配套说明

1. 关键字段清单（你应该在脑子里想清楚这些）

实体字段说明
答主 昵称 / 行业 / 从业年限 / 擅长问题标签 / 脱敏履历 / 自我描述 / 价格 / 开放时段 / 认证状态 / 评分 核心是"标签"主导，不是"履历"主导。脱敏是默认不是选项
用户 昵称 / 身份（学生/在职）/ 关注的问题领域 / 收藏答主 用户侧字段尽量少。ladder 是"找答主"不是"做社交"
预约 答主ID / 用户ID / 时段 / 问题描述 / 价格 / 状态 / 飞单标记 状态：待支付 / 待沟通 / 进行中 / 待评价 / 已完成 / 已退款
评价 评分 / 标签 / 文字 / 是否匿名 / 是否展示在答主主页 标签是评价的核心（沉淀到答主侧）

2. MVP 范围（第一版做什么 / 不做什么）

第一版要做第一版不做
✅ 答主填表 + 标签体系
✅ 用户浏览 + 搜索 + 筛选
✅ 预约 + 支付（微信支付）
✅ 平台内置音视频（25min 倒计时）
✅ 评价 + 标签沉淀
✅ 答主收益 + 提现
✅ 飞单防御协议 + 关键词检测		 ❌ 完整 LinkedIn 履历展示
❌ 答主之间的关注/互动
❌ 群聊/社区/动态
❌ AI 答主/数字人
❌ 直播/录播课
❌ 多人咨询
❌ 复杂会员体系

3. MVP 验证的核心指标

指标目标为什么
答主 → 用户转化率 ≥ 30% 证明"看得到答主" → "愿意约"是顺畅的
通话完成率 ≥ 80% 低于 80% 说明问题描述/匹配有问题
用户评分均值 ≥ 4.5 ladder 的命脉是"高质量答主"口碑
答主周活跃天数 ≥ 3 天 证明答主不是尝鲜就走的
用户复购率（30 天内） ≥ 25% 决定 ladder 是"一次性交易"还是"成长陪伴"
飞单率 ≤ 5% 高了说明产品体验输给了私聊

4. 风险与解法对应表

April 担心的风险对应产品机制
答主简历造假 P3 三选一强制认证（公司邮箱/学信网/LinkedIn）+ 老用户举报 → 复核
答主言论不当 通话前电子协议 + 通话后用户标"不专业"标签累积 → 黑名单
飞单（私下建联） P4 协议强制勾选 + P5 平台内置音视频（禁录） + 关键词检测 + 答主"粉丝/复购"沉淀
April 自己的隐私 默认脱敏 + 可申请"完全匿名" + 平台内置通话（不依赖微信） + 通话四角水印

5. 开放问题（建议你接着想）

  1. ladder 平台抽成比例？建议 15-20%（比在行低，比知乎高）
  2. 第一个月想做多少答主？建议 20-30 个，全 April 自己 1v1 拉
  3. 第一个月想做多少用户？建议 200-500，从 1-2 个垂直社群切入
  4. 小程序 vs H5 vs App？建议小程序，复用微信生态
  5. 要不要做"交换"模式（非货币）？建议第二版考虑，第一版聚焦"付费咨询"心智
